# 上图馆藏查询 · 浏览器扩展

Edge / Chrome 侧边栏扩展：在豆瓣图书详情页直接看这本书在上海各图书馆**有没有、能借几册、
此刻开不开门、离你多远**，顺手复制索书号或导航过去。

> **非官方项目**，与上海图书馆、豆瓣均无隶属或合作关系，仅供个人查询辅助使用。
> 馆藏数据来自公开页面，界面出现的名称与标识归各自所有者，见文末说明。

这个仓库放扩展的项目页和隐私政策。商店后台要求填一个公开可访问的隐私政策地址，
Pages 发的就是这个仓，地址：<https://giant-apple.github.io/shlib-finder-extension/privacy.html>。

## 装

从 [Microsoft Edge 加载项](https://microsoftedge.microsoft.com/addons) 搜「上图馆藏查询」
（上架后这里换成直链）。装完点浏览器工具栏上的书本图标即可。

Chrome 也能用同一份包，商店链接稍后补。

## 能做什么

- **馆藏列表**：按可借册数或离你的距离排序，每个网点给「可借 / 总复本」、开放时间和营业状态。
- **索书号与库室**：展开一行看这家的索书号和库室，点一下复制，到馆里直接照着找。
- **导航**：把网点位置交给高德地图，能搜到路线的那一档。
- **本书其他版本**：同一本书在上图还有别的版本（不同出版社、不同年）时列出来，点一下就换成那一版再查。
- 结果在本浏览器会话里缓存 12 小时，重开同一本书不用等；关掉浏览器就清空。

这一版刻意**没有**搜索、书架、书单导入和地图。需要那些的是本地版：
<https://github.com/Giant-Apple/shlib-finder>，两边数据互不相通。

## 隐私

条款全文单独成页：[隐私政策](privacy.html)。要点：

- 不收集、不统计、不上传，没有后端服务，也没有任何分析或广告代码。
- 扩展主动发出的请求只有两类：向 `vufind.library.sh.cn` 查这本书的馆藏（和你在浏览器里
  自己打开上图官网是同一件事），以及在豆瓣页面里取它本来就已经在显示的那张封面图。
- 定位只用来算距离，坐标留在本机，不出现在任何请求里。
- 查询结果与版本信息放在浏览器会话存储里，关掉浏览器就清空，不落磁盘。

## 数据与标识

- 网点名称、地址、电话、开放时间取自上海图书馆面向公众的检索页面上公开的网点信息。
- 网点坐标不是上图提供的数据，由地理编码服务生成，属于地图服务商的数据；
  扩展包里的这份坐标**仅作非商业用途**分发，仅为让使用者不必重复几百次地理编码请求。
- 上海图书馆、豆瓣的名称与标识权利归各自所有者，本项目不作商标性使用，
  也不代表其认可、赞助或背书。
