# 上图馆藏查询 · 浏览器扩展

Edge / Chrome 侧边栏扩展：在豆瓣图书详情页直接看这本书在上海各图书馆**有没有、能借几册、此刻开不开门、离你多远**，顺手复制索书号或导航过去。

Windows、macOS、Linux 都能装，不用 Python，也不用在本地起服务。

> **非官方项目**，与上海图书馆、豆瓣均无隶属或合作关系，仅供个人查询辅助使用。
> 馆藏数据来自公开页面，界面出现的名称与标识归各自所有者，见文末说明。

## 安装

在 [Microsoft Edge 加载项](https://microsoftedge.microsoft.com/addons/detail/%E4%B8%8A%E5%9B%BE%E9%A6%86%E8%97%8F%E6%9F%A5%E8%AF%A2/kpdbanjmlkfdaebckkjojfbaheojmjok) 安装（商店里搜「上图馆藏查询」也能找到）。装完点浏览器工具栏上的书本图标即可。

## 能做什么

- **馆藏列表**：按可借册数或离你的距离排序，每个网点给「可借 / 总复本」、开放时间和营业状态。
- **结果筛选**：在「可借 / 全部」下面按馆名收窄；也可以只看此刻营业中的馆。
- **索书号与库室**：展开一行看这家的索书号和库室，点一下复制，到馆里直接照着找。
- **导航**：把网点位置交给高德地图，能搜到路线的那一档。
- **本书其他版本**：把豆瓣「这本书的其他版本」里能读到 ISBN 的版本列成一排，点一下就换成那一版再查；展开后列表下面那条「全部 N 个版本」跳到豆瓣的全量版本页，收起时不出现。这一条只从豆瓣页面读，比其他元素稍晚到，读到至少一条才出现，出现时数字就是最终条数；一条都没读到就没有这一行（豆瓣没列、那一版没标 ISBN、版本页没连上都一样）。
- **馆评分**：馆名右侧一枚赞和一枚「不喜欢」，数字是净额——有多少人喜欢这家馆，和具体哪本书无关。点一下就是一次评分，同一家馆一天一票、投过不能改；「不喜欢」只参与扣减，数字本身不公开。数字要等至少 2 台不同设备赞过才出现，没有数字的馆仍可投。
- 结果在本浏览器会话里缓存 12 小时、版本清单 24 小时，重开同一本书不用等；关掉浏览器就清空。评分快照、当天投票锁和随机安装密钥存在本地存储，关浏览器不清。

这一版**没有**搜索、书架、书单导入和地图。需要那些的是本地版：
<https://github.com/Giant-Apple/shlib-finder>，两边数据互不相通。

## 隐私

条款全文单独成页：[隐私政策](privacy.html)。要点：

- 不收集、不统计，没有任何分析或广告代码。只有「馆评分」会写入云端，而且只在你亲手
  点了赞或「不喜欢」时才发：网点编号、评分结果、时间、版本号、本机派生的设备假名。
  没有账号，云端也换不回你的身份。
- 扩展主动发出的请求只有四类：向 `vufind.library.sh.cn` 查这本书的馆藏；在豆瓣页面里
  取它本来就已经在显示的那张封面图；读「本书其他版本」时，在同一个豆瓣标签页里串行打开
  区块列出的那几个版本页读它们的 ISBN；打开侧边栏时读一次馆评分的公开结果。
- 定位只用来算距离，坐标留在本机，不出现在任何请求里。
- 查询结果与版本信息放在浏览器会话存储里，关掉浏览器就清空；评分快照与当天的投票锁
  放在本地存储。

## 数据与标识

- 网点名称、地址、电话、开放时间取自上海图书馆面向公众的检索页面上公开的网点信息。
- 网点坐标不是上图提供的数据，由地理编码服务生成，属于地图服务商的数据；
  扩展包里的这份坐标**仅作非商业用途**分发，仅为让使用者不必重复几百次地理编码请求。
- 上海图书馆、豆瓣的名称与标识权利归各自所有者，本项目不作商标性使用，
  也不代表其认可、赞助或背书。
